# Gaussian Splatting Lightning (Fork)

This repository is forked from [yzslab/gaussian-splatting-lightning](https://github.com/yzslab/gaussian-splatting-lightning). The purpose of this fork is to propose a merge request to the original repository, demonstrating the integration of our custom forward/backward CUDA Kernels [ds-splat](https://github.com/deepsense-ai/ds-splat), into the 3D Gaussian Splatting rasterizer.

## Purpose

- **Merge Request**: Another branch in this repository (`ds_splat_support`) is intended to be a merge request to the original `gaussian-splatting-lightning` repository.
- **CUDA Kernels**: See our forward and backward CUDA Kernels at [ds-splat](https://github.com/deepsense-ai/ds-splat).

## Contribution

Please feel free to review the changes and provide any feedback or suggestions to help improve the integration.
